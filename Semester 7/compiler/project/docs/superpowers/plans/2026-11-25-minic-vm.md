# Mini-C Bytecode Compiler and Portable Stack Virtual Machine (`minic-vm`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a complete, modular Mini-C compiler (`minic`) and deterministic stack virtual machine (`minic-vm`) with full-stage visualization, static semantic analysis, and `.mbc` binary bytecode execution on Linux and Android.

**Architecture:** A multi-pass pipeline where Flex/Bison constructs an AST with source coordinates; a scoped symbol table and semantic analyzer enforce type rules and insert implicit promotions (`AST_CAST_I2F`) to produce a Typed AST; a bytecode generator lowers the typed AST into a compact binary `.mbc` bytecode file; and a portable C99 stack VM interprets the instructions with optional live execution tracing.

**Tech Stack:** C99 (`gcc` / `clang`), Flex (2.6+), GNU Bison (3.8+), GNU Make.

**Spec:** [2026-11-25-minic-vm-design.md](file:///home/sharafat/Desktop/xplore/Semester%207%20%28academics%29/compiler/project/docs/superpowers/specs/2026-11-25-minic-vm-design.md)

## Global Constraints

- Must compile under strict C99 (`-std=c99 -Wall -Wextra -pedantic`) with zero third-party runtime dependencies.
- Compatible with GNU/Linux and Android Termux environments.
- Bytecode file format must strictly follow the 24-byte magic header `\x7fMBC` format specified in Section 6 of the spec.
- All errors (syntax, semantic, runtime) must report clear messages and exit with designated status codes (syntax/semantic = 1, runtime div-by-zero = 2).
- All command executions must use `rtk` (Rust Token Killer) to minimize token consumption.

## Review Focus

- Division by zero at runtime: `10 / 0` or `3.5 / 0.0` must be detected by the VM and cleanly exit with code 2 rather than crash the host OS.
- Undeclared identifier: Referencing any variable not in scope must trigger a clean compile-time error and exit with code 1.
- Duplicate declaration: Re-declaring a variable within the same scope depth must trigger a clean compile-time error and exit with code 1.
- Implicit type promotion: Mixed arithmetic `10 + 2.5` must insert an `AST_CAST_I2F` node and produce a floating-point result in the VM.
- Type mismatch: Assigning a `float` into an `int` variable must fail semantic validation with code 1.

Create `src/common/ast.h`:
```c
#ifndef MINIC_AST_H
#define MINIC_AST_H

#include <stdint.h>
#include <stdbool.h>
#include "value.h"

typedef enum {
    NODE_PROGRAM,
    NODE_FUNC_DEF,
    NODE_BLOCK,
    NODE_DECL,
    NODE_ASSIGN,
    NODE_IF,
    NODE_WHILE,
    NODE_RETURN,
    NODE_PRINT,
    NODE_BINARY_OP,
    NODE_UNARY_OP,
    NODE_LITERAL_INT,
    NODE_LITERAL_FLOAT,
    NODE_VAR,
    NODE_CAST_I2F
} ASTNodeType;

typedef struct ASTNode {
    ASTNodeType type;
    DataType data_type;
    int line;
    int col;
    union {
        struct { char *name; struct ASTNode *body; } func;
        struct { struct ASTNode **stmts; int count; int capacity; } block;
        struct { char *name; DataType declared_type; struct ASTNode *init_expr; int slot; } decl;
        struct { char *name; struct ASTNode *rhs; int slot; } assign;
        struct { struct ASTNode *cond; struct ASTNode *then_branch; struct ASTNode *else_branch; } if_stmt;
        struct { struct ASTNode *cond; struct ASTNode *body; } while_stmt;
        struct { struct ASTNode *expr; } return_stmt;
        struct { struct ASTNode *expr; bool newline; } print_stmt;
        struct { int op; struct ASTNode *left; struct ASTNode *right; } binary;
        struct { int op; struct ASTNode *operand; } unary;
        struct { char *name; int slot; } var;
        struct { int64_t val; } lit_int;
        struct { double val; } lit_float;
        struct { struct ASTNode *expr; } cast;
    } as;
} ASTNode;

ASTNode *ast_new_literal_int(int64_t val, int line, int col);
ASTNode *ast_new_literal_float(double val, int line, int col);
ASTNode *ast_new_var(const char *name, int line, int col);
ASTNode *ast_new_binary_op(int op, ASTNode *left, ASTNode *right, int line, int col);
ASTNode *ast_new_unary_op(int op, ASTNode *operand, int line, int col);
ASTNode *ast_new_decl(const char *name, DataType declared_type, ASTNode *init_expr, int line, int col);
ASTNode *ast_new_assign(const char *name, ASTNode *rhs, int line, int col);
ASTNode *ast_new_if(ASTNode *cond, ASTNode *then_branch, ASTNode *else_branch, int line, int col);
ASTNode *ast_new_while(ASTNode *cond, ASTNode *body, int line, int col);
ASTNode *ast_new_return(ASTNode *expr, int line, int col);
ASTNode *ast_new_print(ASTNode *expr, bool newline, int line, int col);
ASTNode *ast_new_block(int line, int col);
void ast_block_append(ASTNode *block, ASTNode *stmt);
ASTNode *ast_new_func_def(const char *name, ASTNode *body, int line, int col);
ASTNode *ast_new_cast_i2f(ASTNode *expr);
void ast_print(const ASTNode *node, int indent);
void ast_free(ASTNode *node);

#endif
```
