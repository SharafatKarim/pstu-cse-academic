exit

exit

exit

end

#To Verify


🔍 R1 / R2 / R3 — Interface Verification
show ip interface brief

IP এবং interface status দেখার জন্য।

show ip interface

প্রতিটি interface-এর বিস্তারিত information দেখার জন্য।

show running-config

বর্তমান configuration সম্পূর্ণ দেখার জন্য।

show startup-config

NVRAM-এ saved configuration দেখার জন্য।


🔵 OSPF Verification
1. OSPF Neighbors
show ip ospf neighbor

R1 ↔ R2 ↔ R3 OSPF adjacency তৈরি হয়েছে কিনা দেখবে।

2. OSPF Protocol Information
show ip protocols

OSPF process ID, Router ID, advertised networks ইত্যাদি দেখবে।

3. OSPF Information
show ip ospf

OSPF-এর overall information দেখবে।

4. OSPF Interface
show ip ospf interface

OSPF-enabled interfaces, cost, timers, area ইত্যাদি দেখবে।

5. Specific Interface
show ip ospf interface s0/0/0
show ip ospf interface s0/0/1

নির্দিষ্ট serial interface-এর OSPF information দেখবে।

🛣️ Routing Table Verification
show ip route

সব routing information দেখবে।

শুধু OSPF route দেখতে:

show ip route ospf

Default route দেখতে:

show ip route 0.0.0.0

R2 এবং R3-তে এই command চালালে R1 থেকে আসা default route দেখা উচিত।

🆔 Router ID Verification
show ip ospf

এখানে দেখতে হবে:

Router ID 10.1.1.1

R1-এর জন্য।

R2:

Router ID 10.2.2.2

R3:

Router ID 10.3.3.3

আরও নির্দিষ্টভাবে:

show ip ospf | include ID

💰 OSPF Cost Verification

R1/R2-তে:

show ip ospf interface s0/0/0
show ip ospf interface s0/0/1

R3-তে একই commands দিয়ে cost check করবে:

show ip ospf interface s0/0/0
show ip ospf interface s0/0/1

R3-এর serial interfaces-এ:

Cost 1562

দেখা উচিত।


⏱️ Bandwidth Verification

R1/R2 serial interfaces:

show interfaces s0/0/0
show interfaces s0/0/1

এখানে bandwidth check করতে পারবে।

🔌 Serial / DCE Verification
show controllers serial 0/0/0
show controllers serial 0/0/1

এখানে কোন interface DCE সেটা দেখতে পারবে।

DCE interface-এ clock rate verify করতে:

show running-config interface serial 0/0/0

অথবা:

show running-config interface serial 0/0/1

💾 Configuration Save Verification
show startup-config

এবং:

show running-config

দুটো compare করে দেখতে পারবে configuration save হয়েছে কিনা।
